# Jessie Platform

An immersive narrative platform built with Next.js, Supabase, and cinematic editorial design principles.

## Overview

Jessie Platform is a modular storytelling ecosystem designed for:
- immersive essays
- cinematic publishing
- world-building
- creative direction
- founder narratives

The platform combines:
- dynamic CMS infrastructure
- modular content blocks
- editorial layouts
- cinematic interaction systems
- narrative-driven design

---

## Tech Stack

- Next.js 16
- TypeScript
- Supabase
- Tailwind CSS
- Lenis Smooth Scroll
- Framer Motion
- Vercel

---

## Features

### Immersive Journal System

- Dynamic essay routing
- Modular block renderer
- Cinematic layouts
- Editorial typography
- Fullscreen visual sections
- Ambient quote blocks
- Gallery systems
- Timeline modules

### CMS Infrastructure

- Supabase-powered publishing
- Live essay creation
- Dynamic rendering
- Drag-and-drop block system
- Reusable narrative architecture

### Design System

- Cinematic spacing rhythm
- Editorial hierarchy
- Atmospheric motion
- Responsive layouts
- Modular rendering structure

## Local Development

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## Environment Variables

Create:

```bash
.env.local
```

Add:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```
